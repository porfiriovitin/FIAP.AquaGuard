AquaGuard é uma plataforma inteligente de monitoramento e simulação de risco de enchentes. O projeto combina dados climáticos, vazão de rios, elevação do terreno e imagens de satélite para apoiar decisões preventivas da Defesa Civil e de equipes responsáveis por áreas vulneráveis.

A ideia central do MVP é responder, a partir de uma latitude e longitude:

> Qual é o risco de enchente neste local nas próximas horas e dias?

Para isso, o sistema calcula um índice de risco de 0 a 100 e classifica a região em baixo, moderado, alto ou crítico, transformando dados técnicos em uma resposta simples, visual e acionável.
